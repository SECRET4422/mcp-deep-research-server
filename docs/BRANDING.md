# Branding Guide

## Colors
- Background: #0A0E1A (deep navy)
- Primary: #00D4FF (electric cyan)
- Secondary: #0A7BFF (blue)
- Accent: #00FFD1 (teal)

## Logo Concept
Magnifying glass = Research/Search
Network nodes = Parallel scraping, connected data
Database cylinder = Persistent memory

Combines Search + Scrape + Memory - core of Deep Research MCP
